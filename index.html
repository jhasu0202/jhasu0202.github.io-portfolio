Selected Work

Citrus Disease Detection System

92% Accuracy 2027 Images Real-world dataset

Designed a feature-engineered ML pipeline using HSV, GLCM, and LBP features to classify citrus leaf diseases. Built for environments where deep learning is not practical due to limited data and compute.

Approach

- HSV → color variation - GLCM → texture - LBP → micro patterns - Random Forest classifier

Why this approach

Chosen over CNNs for interpretability and low-resource deployment. Trade-off: slightly lower accuracy but higher stability.

Results

92% accuracy on unseen test set (219 images). Stable under moderate lighting variation.

Limitations

Fails under extreme lighting, overlapping leaves, and unseen diseases.
