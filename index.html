IEEE Publication

IEEE Paper · Computer Vision
Citrus Disease Detection Using Feature Engineering & Machine Learning
Published · IEEE Conference · 2024–25
Proposed and validated a feature-engineered approach to citrus leaf disease classification using HSV color space analysis, GLCM texture features, and LBP local binary patterns — combined with a Random Forest classifier. The paper demonstrates that thoughtful, interpretable feature engineering outperforms CNN-based deep learning on small, structured agricultural datasets with real-world lighting variability. Achieved 92% accuracy on 2,027 training images across multiple disease classes.

Philosophy

How I Think

⚙
Production Over Perfection

A 92% accurate deployable model beats a 97% prototype that breaks outside the lab. I design for noise, variability, and real-world edge cases from day one.

🔍
Interpretability First

Feature-engineered pipelines make predictions explainable and auditable. When stakes are high, I choose transparent models — interpretability is a feature, not a constraint.

⬡
Modular Architecture

Clean separation of concerns across all layers — role-based access, clean API boundaries, schemas built for growth. Systems designed to be extended, not rewritten.

△
Deliberate Trade-offs

Every decision is a trade-off. I consciously balance accuracy vs. speed, complexity vs. maintainability, and feature richness vs. data requirements.
